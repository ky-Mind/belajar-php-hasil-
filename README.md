# belajar-php

Catatan latihan dasar PHP, satu topik per berkas.

| Topik | Berkas |
|---|---|
| Variabel & konstanta | `variable.php`, `constant.php` |
| Tipe data | `tipeDataString.php`, `tipeDataNumber.php`, `tipeDataBoolean.php`, `tipeDataNull.php`, `tipeDataArray.php` |
| Operator | `operatorAritmatika.php`, `operatorPenugasan.php`, `operatorPerbandingan.php`, `operatorLogika.php`, `operatorArray.php`, `incrementAndDicrement.php`, `ternaryOperator.php`, `nullCoalescingOperator.php` |
| Percabangan | `ifStatement.php`, `switchStatement.php` |
| Perulangan | `forLoop.php`, `whileLoop.php`, `doWhileLoop.php`, `forEachLoop.php`, `breakANDContinue.php`, `goTo.php` |
| Fungsi | `function.php`, `functionArgument.php` |
| String | `manipulasiString.php` |

Jalankan satu berkas:

```bash
php forLoop.php
```
